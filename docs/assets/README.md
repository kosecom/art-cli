# Graphics provenance

These graphics were created by issuing native VectorCraft drawing, text, save and export operations through ART-CLI on Windows. They were not generated as screenshots of an open GUI.

- `banner.png`: repository hero and shareable product overview.
- `workflow.png`: agent → integration → selected native applications → save, verify, close.
- `capabilities.png`: the 13 supported application families, with installed-subset and coverage qualifications.

All PNGs are 1600 × 800. Matching SVG exports are included. Each editable `.vectorcraft` source was reopened in a fresh native job and re-exported; its PNG pixels matched the first export. Editable sources are provided in the separate creatives release ZIP, not required by the installer. Text outlines in SVG are vector artwork; no font files are bundled.

The integration is independent and is not affiliated with or endorsed by ArtCraft. The diagrams describe intended workflow, not proof that every native command or format was executed. See the acceptance document for actual verification scope.
