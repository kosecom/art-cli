# Third-party and provenance notice

ART-CLI is an independent kosecom integration for Hermes Agent and the ArtCraft applications published by storytold. It is not a replacement for ArtCraft and is not an official upstream product endorsement.

The stdio transport is adapted from the existing kosecom ArtCraft integration's lazy Python router. Application-specific invocation names/protocols were verified against installed native tools and the corresponding public ArtCraft release sources. The wrapper does not copy the ArtCraft application implementation into this package.

ArtCraft application binaries, artwork, fonts, codecs and source have their own licenses. They are not bundled; obtain official native releases and retain their license notices. Hermes Agent is a separate dependency with its own license.

Upstream repositories: https://github.com/storytold/photocraft, vectorcraft, filmcraft, lightcraft, pdfcraft, effectcraft, designcraft, wordcraft, deckcraft, gridcraft, cadcraft, soundcraft, figcraft (each app is its own repository under storytold).

Native plugin contract: https://hermes-agent.nousresearch.com/docs/developer-guide/plugins
